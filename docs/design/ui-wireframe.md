# Forge Studio - UI 와이어프레임 & 화면 설계

## 메타데이터
- 작성일: 2026-03-06
- 버전: 1.0

---

## 1. 디자인 원칙

| 원칙 | 설명 |
|------|------|
| Developer-First | 개발자가 불편함 없이 쓸 수 있는 정보 밀도. 불필요한 장식 최소화 |
| Dark by Default | 다크 테마 기본. IDE와 통합감 |
| Keyboard-Driven | 모든 주요 동작에 키보드 단축키. Cmd+K 커맨드 팔레트 |
| Progressive Disclosure | 기본은 간단하게, 고급 옵션은 펼쳐서 |
| Real-time Feedback | 모든 변경은 즉시 반영, 저장 버튼 없음 (자동 저장) |

## 4. 반응형 & 리사이즈

- 사이드바: 최소 48px (아이콘만) ~ 최대 240px (아이콘+텍스트)
- 터미널 패널: 최소 120px ~ 최대 화면 60%. 드래그로 리사이즈
- 콘텐츠 영역: 나머지 공간. 최소 600px
- 전체 최소 해상도: 1280x720
